# 《HR.exe》角色设定表（给美术）

配合 `样板图_美术P0.png`（整体）和 `样板图_女性头像.png`（女性画法）看。范围：砍减版 / 第三个月试玩包里出现的所有有名字的人（第 1–23 天）。
资料都取自游戏数据（`data/story`、`data/days`、`data/jobs`）。标“建议”的是剧本没写、我补的，可以改。

## 规格

| 图 | 尺寸 | 用在哪 | 说明 |
|---|---|---|---|
| 小头像 | 64×64 | 简历照片、身份证复印件、面试官位、离职谈话 | 1px 深肤色描边，右脸 2px 暗面，背景统一 `#5a6763` |
| 第二帧 | 64×64 | 同上 | 只改眉、眼、嘴、汗；对白里写 `[冒汗]` `[侧眼]` 等标签就切 |
| 半身像 | 128×128 | 面试间左边的大框 | 单独画，不是把 64 放大。身体共用一张，五个表情只重画脸那一块（约 68×76） |
| 五个表情 | — | 半身像 | 平常 / 冒汗 / 侧眼 / 低头 / 硬撑（硬撑 = 嘴在笑，眉是愁的） |

画布 640×360，按整数倍放大，最近邻采样。所有图都按 1 个游戏像素来画，不要混用像素大小。

### 女性和男性用两套脸

男性保持方脸。女性另用一套画法，规则如下，以 `样板图_女性头像.png` 为准：

| 部位 | 64×64 | 128 半身像 |
|---|---|---|
| 脸型 | 鹅蛋脸：颧骨那一行最宽，往下慢慢收成小下巴；不画方下巴，下巴底不画整行深色描边 | 同左，脖子细一点 |
| 眼睛 | 比男性大一号；上眼线粗、眼尾往上挑 1px，虹膜左上角 1px 高光，下眼睑用浅色 | 眼白 10×5、虹膜 6×5，两格高光，加下睫毛 |
| 眉毛 | 细、带弧度，颜色比头发浅 | 同左 |
| 鼻子、嘴 | 鼻子只点 1–2px 阴影；嘴小，上唇深、下唇浅两种颜色 | 同左，不画法令纹、颧骨下阴影 |
| 腮红 | 一行，很淡 | 同左 |
| 头发 | 头顶是圆的，带一圈高光；脸边垂两缕把脸收窄；长发越往下越散开，披在肩上，不贴脖子 | 刘海带弧度，不画平顶的头发块 |
| 年龄 | 靠发型、衣服、一两根白头发表现，**不画皱纹**；眼下的青只给“疲惫”“硬撑”和本来就累的人（沈雯本人、李秀英） | 同左 |

好看不等于一个模子，每人还是各有记号（见下表“建议记号”）。

优先级：**A** = 半身像 + 五个表情 + 64 两帧；**B** = 64 两帧；**C** = 64 一帧，或者只出现在群像、背影里。

## 三、家里（不给正脸）

家人只画背影和侧影。**正脸只出现在办公桌上那张全家福里**（你爸、你、老婆、孩子四个人，逐像素画）。

| 角色 | 剧情里的外形线索 | 要画 |
|---|---|---|
| **老婆** | 在一家贸易公司做会计。常在厨房；“把手机扣在桌上”；后来问“名单到底是怎么定的？” | 场景里的背影 / 侧影（坐着、站在厨房门口），全家福一张 |
| **孩子** | 小学四年级，男孩。英语听写本、跳绳（一分钟 160 个）、编程班、问“简历是什么” | 场景里写作业的背影，全家福一张；墙上那幅《我的爸爸》 |
| **你爸** | 一个人住在老房子里，胸口闷，不肯去医院；后来住院，“比上次见瘦了一圈”；小刘家送礼时他也在 | 场景里坐沙发的侧影（他来住几天时），全家福一张；生病后瘦一圈的版本 |
| **你** | 主角不露脸 | 只出现在全家福里；拖鞋、你那碗饭、空着的椅子代表你 |

## 四、跟着人走的道具和群演

- **妈妈陪面**：阿姨拎着保温杯先坐下（奇葩面试“妈妈”）。需要一个 64 的阿姨，或者半身像里多一个人。
- **行李箱**：“拖着一个行李箱进来，靠在门边”。
- **三部手机**：海投的人“把两部手机扣在桌上，又摸出第三部”。
- **李哲他爸的信封**、小刘家的购物卡和两条烟一盒茶叶：放在抽屉或茶几上的道具图。
- **老周的手抄规则本**：最后会进你的抽屉，也是结局画面里的证据。
