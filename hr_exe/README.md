# HR.exe — 垂直切片

按《HR.exe》设计文档第 12 页“垂直切片”范围实现，Godot 4.7。

## 运行

用 Godot 4.x 打开本目录的 `project.godot`，按 F5；或：

    godot --path .

## 玩法（第一个月，第 1–5 天）

晨会邮件与早间推送 → 筛简历 → 面试 → 日结 → 报纸与短信 → 第二天。第 3、5 天早上，之前录用的人回来找你。
经济下行线的设计见仓库根目录 `设计文档_经济下行线.md`。

- 每 5 个工作日算一个月，日期跳着走（3/2、3/3、3/4、3/18、3/31）。房贷 ¥1250 只在月底（第 5 天）扣，日结单上有“距月底还房贷”进度条。
- 早间推送预告当天的新规则；桌上的职位描述（JD）每月换一张，这个月招“管培生（实习）”。
- 简历堆按 `candidate_mix` 混入应届生、转行者、被裁的人，经济越差后两类越多。
- 第 4 天新规则“第一学历必须名校”：读了研的看本科那行，名校的独立学院不算。

- 把“通过/拒绝”印章拖到简历上；拒绝必须选一句理由。简历可翻页，文件可拖动。
- 对错当晚才在违规通知单上揭晓。前 2 次违规只警告，之后每次 −¥50。
- 面试由你和赵主管共同进行：从 10 张问题卡里选 2 张，主管抢走第 3 问，并按“像不像标准答案”当场改评分表。
- 候选人会反问，你选话术、敷衍或实话：话术入职后反噬，实话让有能力的人当场走。之后填老板评分表，决定是否录用。
- Esc 或右下角“菜单”暂停（桌上的钟也停）：存档、退出到主菜单。存档点是每天早上：每天开始时自动存，
  手动存也存今天早上的状态，今天做到一半的不会存进去。标题页“继续”从存档的那天早上接着玩。
- 账单可以不付，代价进隐藏的家庭状态；存款为负提前结束（实际上多半发生在月底还房贷那天）。

## 目录

与设计文档一致：`autoload/` 单例，`data/` 规则、问题、每日配置、剧情候选人（`.tres`，改数值不碰代码），
`scripts/resources/` 数据类，`scripts/generators/` 生成器与员工事件，`scenes/` 场景。

新增规则：继承 `Rule`，实现 `check()`（判定）和 `shape()`（生成边界简历），再挂进某天的 `new_rules`。

## 与设计文档的差异

- 延迟反馈压缩：设计是 3–7 天，切片改为第 3、5 天早上各结算一位最早录用、还没结果的人；其余留作悬念。
- 问题卡 10 张、每天面试 1 人（文档写 3 张、1 位），否则“选 3 张”没有选择，后两天也没有面试环节。
- 新增部门主管赵主管与候选人反问（文档没有）。诉讼风险、反问原话已累积进存档，等违法规则线和终章使用。
- 提前加入了简化的老板对质（甩锅三选一）、报纸、家人短信：延迟事件需要一个落点。
- 中国版不让玩家做算术：年龄改为“只要 90 后”（看出生年份），薪资改为月薪上限（区间看上限），
  空窗期不数月份，改为看简历上的空窗说明（家庭、生育、身体或没写的拒绝），另加“不要裸辞”。
  陷阱来自读漏（1989.12、16–19k、“家中有事”、这个月刚离职、附注自称已离职），不来自算错。桌上不再有计算器和日历。
- 暂未实现：`tr()` 本地化与美国版规则、高亮笔、“质询”按钮、音乐。头像、界面、音效均为程序生成的占位。
- 界面由代码搭建，`.tscn` 只挂脚本。
